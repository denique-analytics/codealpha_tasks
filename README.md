# CodeAlpha Data Analytics Tasks

This repository contains the data analytics projects completed as part of the CodeAlpha internship.

## Tasks

### Task 1: Web Scraping
Scraped anime information from Anime-Planet using Python, Requests, and BeautifulSoup.

The dataset contains:
- Anime Title
- Rating
- URL

### Task 2: Exploratory Data Analysis
Performed exploratory analysis using Pandas.

The analysis included:
- Dataset structure
- Data types
- Missing values
- Duplicate records
- Rating statistics
- Highest and lowest ratings
- Rating distribution

### Task 3: Data Visualization
Created visualizations using Matplotlib to identify patterns and trends in anime ratings.

Visualizations include:
- Anime Rating Distribution
- Highest-Rated Anime
- Percentage of Anime by Rating
- Distribution of Anime Ratings

## Tools Used

- Python
- Pandas
- Requests
- BeautifulSoup
- Matplotlib
- Jupyter/VS Code
- GitHub
